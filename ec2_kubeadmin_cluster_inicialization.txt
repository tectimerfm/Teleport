Kubeadm installation command for creating the Control Plane:

sudo kubeadm init \
  --pod-network-cidr=10.244.0.0/16 \
  --cri-socket=unix:///run/containerd/containerd.sock

Command to make Kubeconfig available for access by a non-root local user:
mkdir -p $HOME/.kube
sudo cp /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

Command to initialize kubeadm and add nodes to the cluster:
sudo kubeadm join 172.31.14.198:6443 \
--token hdbks4.2hdsq6nijjbd99ty \
--discovery-token-ca-cert-hash sha256:ee5ac3271abc3431f84b6aa8c03bb9460d408cc569d7a69d4c9827335f11504b
